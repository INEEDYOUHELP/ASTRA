## 0. 部署前准备

### 0.1 地址（写入 `.env`）

| 变量 | 含义 |
|------|------|
| `ADMIN_SAFE` | 协议管理员多签（2/3） |
| `ECO_FUND_SAFE` | 生态基金 40% 接收地址 |
| `LIQUIDITY_SAFE` | 流动性拨备 5% 接收地址 |
| `KEEPER` | `KEEPER_ROLE` / Oracle 更新（可先 EOA） |
| `TEAM_BENEFICIARY` | 团队归属受益人 |
| `INVESTOR_BENEFICIARY` | 投资者归属受益人 |
| `RPC_URL` / `PRIVATE_KEY` | 测试网部署用（勿提交） |

本地可先不填 Safe：跑 `deployAll.ts` 会自动部署三套 `AstraSafe(2/3)`。

### 0.2 经济参数

见 `scripts/config.ts` → `DEFAULT_PARAMS`（奖励速率、vesting 时长、burn 阈值等）。上线前按预算修改。

## 1. 正确部署顺序（当前构造函数依赖）

**不要**先部署 Token。Token 构造时要把币 mint 到 Staking / Vesting / Safe：

```text
1. AdminSafe / EcoFundSafe / LiquiditySafe   （AstraSafe 或官方 Safe）
2. AstraVesting(adminSafe)
3. AstraStaking(adminSafe)
4. AstraReferral(adminSafe)
5. MockOracleAdapter(adminSafe)
6. AstraToken(adminSafe, ecoFund, staking, vesting, liquidity)
7. AstraBurnController(adminSafe, token, staking, oracle)
8. 配置绑定 + 角色 + vesting 计划（须 AdminSafe 权限）
9. （可选，M4 后半）Uniswap addLiquidity
```

一键：

```bash
npx hardhat run scripts/deployAll.ts
```

仅 Safe：

```bash
npx hardhat run scripts/deploySafes.ts
```

## 2. 逐合约要点（与代码一致）

### 2.1 AstraToken

- 构造一次性 mint：40% Eco / 30% Staking / 15%+10% Vesting / 5% Liquidity  
- 部署后：`grantRole(BURNER_ROLE, burnController)`

### 2.2 AstraVesting

- `setAstraToken(token)`（一次性）  
- `createSchedule(beneficiary, totalAmount, start, cliff, duration)`  
  - 团队：150M，cliff 180 天，线性 730 天  
  - 投资者：100M，cliff 0，线性 540 天  
- 受益人 `release()` 领取  

### 2.3 AstraStaking

- `setAstraToken` → `setReferral` → `setBurnController` → `setRewardRatePerSec`  
- 用户：`stake(amount, referrer)` / `unstake` / `claimReward`  
- Burn：`transferForBurn` 仅 BurnController  

### 2.4 AstraReferral

- `setAstraToken` → `setStaking`  
- 仅 Staking 可 `accrueOnFirstStake`；推荐人 `claimReferralReward`  

### 2.5 MockOracleAdapter + AstraBurnController

- Oracle：`setMetrics(netLiq, deviation)`（`ORACLE_UPDATER_ROLE`）  
- Burn：`setParams(...)`；Keeper `checkAndBurn()`  
- 前置：`staking.setBurnController` + Token `BURNER_ROLE`  

### 2.6 AstraSafe

- 见 [多签Safe部署与接入.md](./多签Safe部署与接入.md)  
- `AstraTreasury` 仍为可选，当前加池可直接从 `LiquiditySafe` 转出

## 3. 配置步骤清单（脚本已覆盖）

当 AdminSafe 为本仓库 `AstraSafe` 时，`deployAll.ts` 会用 **2 名 owner 确认** 自动执行：

1. vesting/staking/referral 的 `setAstraToken`  
2. staking `setReferral` / `setBurnController` / `setRewardRatePerSec`  
3. referral `setStaking`  
4. token `grantRole(BURNER_ROLE, burn)`  
5. burn `setParams` + `grantRole(KEEPER)`  
6. oracle `grantRole(ORACLE_UPDATER)`  
7. 两条 `createSchedule`  

官方 Gnosis Safe：在 Safe UI 按同表手动发交易。

## 4. 链上验证清单

### 4.1 分配

- EcoFundSafe = 400M  
- Staking = 300M  
- Vesting = 250M  
- LiquiditySafe = 50M  
- 四者和 = 1B  

### 4.2 多签

- AdminSafe `threshold == 2`，`owners.length == 3`  
- 单签无法 `executeTransaction`；2 确认后可改 `rewardRate` 等  

### 4.3 功能

- Vesting cliff / 线性；Staking 奖励与 3M 锁；Referral 5%；Burn epoch 防重  

### 4.4 Uniswap 加池（待脚本补全时）

- 从 LiquiditySafe 支出 ASTRA + ETH  
- Router `addLiquidityETH`  
- LP 打到指定接收地址（建议仍为 LiquiditySafe 或 AdminSafe）
