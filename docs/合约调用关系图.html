基于当前仓库实现：标注跨合约方法、参数与调用方向。 覆盖 Token / Vesting / Staking / Referral / Burn / Oracle（Hardhat 模板已清理）。

AstraToken AstraVesting AstraStaking AstraReferral BurnController MockOracle 外部角色

关键场景调用链（含参数）

  1. User 先对 Token 授权： AstraToken.approve(staking, amount)
  2. User AstraStaking.stake(uint256 amount, address referrer)
  3. Staking → Token transferFrom(user, staking, amount) — 本金进入质押合约
  4. Staking → Referral （仅首次且 referrer != 0） accrueOnFirstStake(user, firstStakeAmount=amount, referrer) → 返回 reward = amount * 500 / 10000
  5. Staking → Token → Referral safeTransfer(referral, referralReward) — 社区奖励池出账到 Referral 托管
  6. 推荐人 之后可调用 AstraReferral.claimReferralReward() → Token.safeTransfer(referrer, pending)
  1. User AstraStaking.claimReward() 或 claim()（无参数别名）
  2. Staking 内部 updatePool() 更新 accRewardPerShare
  3. Staking → Token safeTransfer(user, pending)
  4. User 赎回： AstraStaking.unstake(uint256 amount) → 先发 pending 奖励，再 safeTransfer(user, amount) 退本金
  1. Admin AstraVesting.setAstraToken(address token)
  2. Admin createSchedule(beneficiary, totalAmount, start, cliff, duration)
  3. 受益人 AstraVesting.release() — 无入参，领取人为 msg.sender
  4. Vesting → Token safeTransfer(beneficiary, releasable)
  1. Keeper / Updater MockOracleAdapter.setMetrics(uint256 netLiquidityAddedETH_, uint256 priceDeviationBps_)
  2. Keeper AstraBurnController.checkAndBurn() — 无入参；读 Oracle + 本合约参数
  3. 条件： netLiq < minLiquidityAddedETH 且 deviation > maxPriceDeviationBps 且本 epoch 未烧过
  4. Burn → Staking rewardPoolBalance() 计算额度； transferForBurn(uint256 amount)
  5. Staking → Token safeTransfer(burnController, amount)
  6. Burn → Token burn(uint256 amount) — 销毁调用者（BurnController）余额；需 BURNER_ROLE
  1. 部署顺序建议：Vesting → Staking → Referral → Oracle → Token（mint 到各地址）→ BurnController
  2. Token.constructor(adminSafe, ecosystemFund, communityRewardPool=staking, vestingContract, liquidityReserve)
  3. staking.setAstraToken(token) · staking.setReferral(referral) · staking.setBurnController(burn)
  4. referral.setAstraToken(token) · referral.setStaking(staking)
  5. vesting.setAstraToken(token)
  6. token.grantRole(BURNER_ROLE, burnController)
  7. burn.setParams(epochDuration, minLiquidityAddedETH, maxPriceDeviationBps, burnBps, maxBurnPerEpoch)

各合约对外方法一览

AstraToken

  • constructor(adminSafe, ecosystemFund, communityRewardPool, vestingContract, liquidityReserve)
  • burn(uint256 amount) BURNER_ROLE
  • 标准 ERC20 / Permit / AccessControl

AstraVesting

  • setAstraToken(address token) Admin
  • createSchedule(beneficiary, totalAmount, start, cliff, duration) Admin
  • release() 受益人
  • releasable(address) / getSchedule(address) 读

AstraStaking

  • setAstraToken / setReferral / setBurnController Admin
  • setRewardRatePerSec(uint256) PARAM_SETTER
  • stake(uint256 amount, address referrer)
  • unstake(uint256 amount) / claimReward()
  • transferForBurn(uint256 amount) 仅 BurnController
  • rewardPoolBalance() / pendingReward(user) 读

AstraReferral

  • setAstraToken / setStaking Admin
  • accrueOnFirstStake(user, firstStakeAmount, referrer) → reward 仅 Staking
  • claimReferralReward()
  • pendingReferralReward(referrer) / referrerOf(user) 读

AstraBurnController

  • constructor(adminSafe, token_, staking_, oracle_)
  • setStaking / setOracle Admin
  • setParams(epochDuration, minLiquidityAddedETH, maxPriceDeviationBps, burnBps, maxBurnPerEpoch) PARAM_SETTER
  • checkAndBurn() → burned KEEPER
  • previewBurnAmount() / currentEpoch() 读

MockOracleAdapter

  • setMetrics(netLiquidityAddedETH_, priceDeviationBps_) ORACLE_UPDATER
  • public：netLiquidityAddedETH / priceDeviationBps / updatedAt
