## 2) M5 理解标注（Burn 怎么读）

### 资金流（一句话）

Oracle 写入差指标 → Keeper 调 `checkAndBurn` → 从 **Staking 奖励池** 划到 BurnController → `token.burn` 减总供应。

```text
MockOracleAdapter.setMetrics(netLiq, deviation)
        │
        ▼
 Keeper: BurnController.checkAndBurn()
        │  条件：netLiq < min  AND  deviation > max  AND  本 epoch 未烧过
        ▼
 burnAmount = min(rewardPool × burnBps/10000, maxBurnPerEpoch)
        │
        ▼
 Staking.transferForBurn(amount)   ← 只动奖励池，不动质押本金
        │
        ▼
 Token.burn(amount)                ← BurnController 须持有 BURNER_ROLE
```

### 关键文件

| 文件 | 看点 |
|------|------|
| `contracts/AstraBurnController.sol` | 文件头流程注释；`checkAndBurn`；`setParams` 上限 |
| `contracts/MockOracleAdapter.sol` | 链下指标上链的 mock |
| `contracts/AstraStaking.sol` | `setBurnController` / `transferForBurn` |
| `test/AstraBurnController.test.ts` | 条件满足/不满足、同 epoch 防重、权限 |

### 部署时必做授权

1. `token.grantRole(BURNER_ROLE, burnController)`
2. `staking.setBurnController(burnController)`
3. `burnController.setParams(...)` + 授 `KEEPER_ROLE`
